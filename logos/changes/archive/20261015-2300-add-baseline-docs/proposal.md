# 变更提案：add-baseline-docs

> module: core | created: 2026-10-14

## 变更原因
集群部署验证已完成，准备推送时的文档检查发现新增包的 README、中英配对、公共类型文档和 JSDoc 不完整。补齐现有实现的文档基线，使文档检查可复现通过。

## 变更类型
代码级：文档、注释和生成目录维护。

## 变更范围
- 影响的需求文档：core 逆向基线的来源说明。
- 影响的功能规格：无功能变更。
- 影响的业务场景：现有 Fleet 和集群部署文档。
- 影响的 API：补齐现有字段和方法的文档，不改变签名。
- 影响的 DB 表：无。
- 影响的编排测试：文档结构和生成目录检查。

## 部署影响
- 是否需要部署：否
- 部署原因：仅更新文档、注释和生成索引，不改变运行时行为。
- 影响环境：无
- 是否涉及数据迁移：否
- 是否需要回滚预案：否
- 是否需要 smoke：否

## 变更概述
补齐新增包 README 双语结构、示例依赖、限制和模型影响描述，为租约及流转发类型补充所属子系统文档。完善公开 JSDoc，由仓库生成器更新配置、插件、类型路径和文档图目录。

修复维护文档的来源链接与术语，复核中英配对后记录 sidecar。执行 test:docs、doc-sync、lint 和差异检查，通过后提交并推送当前分支。
